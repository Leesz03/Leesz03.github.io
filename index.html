Accentury — 경상도 사투리 억양 레벨 테스트

AI·SW 마에스트로 제17기 · 3인 팀 · 2026.07 ~ 진행 중

기준 억양사용자 발화

버튼을 누르고 아무 말이나 해 보세요. 곡선은 Accentury 웹앱의 실제 코드(마이크 캡처 · YIN 피치 추정 · 곡선 스무딩)를 그대로 묶어 브라우저에서 계산합니다. 음성은 어디에도 전송되지 않습니다.

문제 정의

사투리는 단어보다 억양에서 티가 난다. 그런데 억양은 글로 설명하기 어렵고, 내가 제대로 따라 했는지 스스로 확인할 방법도 없다. 기존 발음 교정 앱은 표준어 분절음(자음·모음) 위주라 경상도 말투의 높낮이를 평가하지 못한다. 게다가 사투리에는 "정답 억양"이 하나로 정해져 있지 않다. Accentury는 사용자가 제시된 문장을 말하면 억양 곡선을 바로 보여주고, 서버가 경남 화자들의 억양 분포와 비교해 1~5단계 레벨(외지인 → 경상도 토박이)을 판정한다.

역할 — 팀장 · 프론트엔드 전담

3인 팀(프론트엔드·백엔드·AI)에서 사용자가 보고 만지는 부분 전체를 맡았습니다. 웹 UI, Android·iOS 네이티브 셸, 둘을 잇는 브리지, 배포까지 담당했습니다.

웹 UI (React)

온보딩, 방언 지도, 녹음, 결과 카드, 공유 화면을 React 19 + TypeScript로 구현. 한 번 만든 화면을 앱과 브라우저에 그대로 사용.

WebView 하이브리드 구조

화면은 웹이 그리고 마이크·녹음·공유는 네이티브가 처리하도록 나눔. 버전을 매긴 브리지 계약을 설계해 Android·iOS·웹 세 곳이 같은 메시지 형식을 쓰게 함.

실시간 억양 곡선

마이크 입력을 프레임 단위로 잘라 YIN 알고리즘으로 음높이를 추정하고, EMA 스무딩과 베지어 보간으로 말하는 동안 곡선이 끊김 없이 그려지게 함.

디자인 시스템·품질

색·타이포·간격을 디자인 토큰으로 정리해 웹(CSS)과 Android(Compose)가 같은 값을 쓰게 함. Vitest 단위 테스트와 Playwright 브라우저 E2E로 회귀 확인.

사용자 흐름

  1. 방언 지도 온보딩에서 출신 지역 선택
  2. 화면에 제시된 문장을 읽으면 억양 곡선이 실시간으로 그려짐
  3. 녹음이 끝나면 서버 채점 결과를 기다리는 동안 진행 상태 표시
  4. 레벨 1~5(외지인 → 경상도 토박이)와 캐릭터가 담긴 결과 카드 확인
  5. 결과 카드를 링크·이미지로 공유
