Accentury — 경상도 사투리 억양 레벨 테스트

AI·SW 마에스트로 제17기 · 3인 팀 · 2026.07 ~ 진행 중

기준 억양사용자 발화

앱이 보여주는 핵심 화면을 단순화한 그림. 말하는 동안 억양(F0) 곡선이 실시간으로 그려진다.

문제 정의

사투리는 단어보다 억양에서 티가 난다. 그런데 억양은 글로 설명하기 어렵고, 내가 제대로 따라 했는지 스스로 확인할 방법도 없다. 기존 발음 교정 앱은 표준어 분절음(자음·모음) 위주라 경상도 말투의 높낮이를 평가하지 못한다. 게다가 사투리에는 "정답 억양"이 하나로 정해져 있지 않다. Accentury는 사용자가 제시된 문장을 말하면 억양 곡선을 바로 보여주고, 서버가 경남 화자들의 억양 분포와 비교해 1~5단계 레벨(외지인 → 경상도 토박이)을 판정한다.

역할 — 팀장 · 클라이언트 전담

클라이언트 3종 개발

Android(Kotlin), iOS(Swift), Web(React)을 전담해 녹음 → 업로드 → 결과 카드 → 공유 흐름을 세 플랫폼에 같은 동작으로 구현.

온디바이스 피치 시각화

16kHz 모노 PCM을 실시간으로 받아 YIN/MPM으로 피치를 뽑고, EMA 스무딩과 무성 구간 처리로 100ms 이하 곡선 갱신 목표를 맞춤.

릴리스·운영

GitHub Actions로 Dev → staging, Release → prod 배포 파이프라인 구성. Android 서명·R8, 개인정보처리방침·계정 삭제 페이지 등 스토어 심사 대응.

팀 리딩

Jira 티켓 단위 일정 관리, 브랜치 규칙(Rebase 전용·Squash 금지) 설계, 모노레포를 App/Server로 분리하는 작업 주도.

동작 흐름

  1. 방언 지도 온보딩 후 고정 문장을 화면에 제시
  2. 녹음하는 동안 기기에서 억양 곡선을 실시간으로 그림
  3. Spring Boot 백엔드가 음성을 받아 사설망의 FastAPI 채점 서버로 전달
  4. STT로 대사 확인 → RMVPE로 F0 추출 → 화자 정규화 → DTW로 기준 억양과 정렬·채점
  5. 레벨 1~5와 점수, 억양 곡선이 담긴 결과 카드를 받아 공유
